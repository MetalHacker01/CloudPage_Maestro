Documentation / Overview

CloudPage Maestro

Advanced Tampermonkey script for Salesforce Marketing Cloud (SFMC) CloudPages management with enhanced UI, real-time asset enrichment, and complete download capabilities. Advanced Chrome Extension for Salesforce Marketing Cloud (SFMC) CloudPages management with batch operations, folder management, real-time asset enrichment, and complete download capabilities.

Version

This documentation covers CloudPage Maestro v5.0 Tampermonkey - userscript with download functionality, bouncing animations, and defaultPageId display.

This documentation covers CloudPage Maestro v5.0 Chrome Extension - with batch operations, folder picker UI, download functionality, and production-ready debug mode.

Features

  • Dual-Token System - Automatically captures and manages SFMC authentication tokens
  • Asset Management - View, search, and manage CloudPages and Code Resources
  • Download System - Download HTML from landing pages and content from code resources
  • Real-time Enrichment - Fetch asset details, status, and site information on-demand
  • Unpublish Operations - Safely unpublish landing pages with confirmation
  • Smart Caching - Local caching with time-based expiration (15 minutes)
  • Advanced UI - Icons, tooltips, and bouncing download animations
  • Batch Operations - Select multiple assets with checkboxes for batch publish/unpublish/move
  • Folder Management - Visual folder tree picker with search and multi-page folder fetching
  • Debug Mode - Production-ready logging with DEBUG_MODE flag

Installation

  1. Install Tampermonkey browser extension
  2. Create a new script in Tampermonkey dashboard
  3. Copy the CloudPage Maestro v5 code
  4. Save and enable the script
  5. Navigate to SFMC CloudPages section
  6. Script automatically captures tokens and activates
Developer Mode

Currently available for installation in Developer Mode only. Chrome Web Store release coming soon.

  1. Download the Chrome Extension folder (Chrome_Extension/)
  2. Open Chrome and navigate to chrome://extensions/
  3. Enable "Developer mode" (toggle in top-right corner)
  4. Click "Load unpacked"
  5. Select the Chrome_Extension/ folder
  6. Verify extension appears with CloudPage Maestro icon
  7. Navigate to SFMC CloudPages section
  8. Extension automatically activates and captures tokens

Extension Architecture

  • content_full.js - Main content script (4077 lines) with UI and API logic
  • background.js - Service worker for CORS bypass via chrome.runtime.sendMessage
  • manifest.json - Extension configuration with permissions for SFMC domains
Requirements

SFMC account with CloudPages access and valid session credentials required. ScriptExtension only works within authenticated SFMC sessions.

CloudPage Maestro uses a sophisticated multi-layered architecture combining token management, API orchestration, and UI rendering.

Components

  • UI Layer - React-style rendering with event delegation and state management
  • Token Management - Dual-token capture and refresh system
  • API Orchestration - Coordinated multi-step API flows
  • Cache Manager - localStorage-based caching with TTL

Token System

CloudPage Maestro uses a dual-token authentication system to access different SFMC API endpoints.

Token Types

Token Source Used For Capture Method
pageHookToken Content Builder Asset queries, Code Resources DOM extraction from _pageHook
appcoreToken CloudPages UI Landing Pages, Sites, States, Contents Network request interception

Token Capture Flow

sequenceDiagram participant User participant Script participant SFMC participant Storage User->>SFMC: Navigate to CloudPages SFMC->>Script: Page loads with tokens Script->>Script: Extract pageHookToken from DOM Script->>Script: Intercept network for appcoreToken Script->>Storage: Save tokens to localStorage Script->>User: Display token status Note over Script,Storage: Tokens cached for session
Security

Tokens are session-specific and stored in localStorage. Never share tokens or expose them in logs. Tokens automatically expire with SFMC session.

Data Flow

Asset enrichment follows a multi-step data fetching and merging process.

Enrichment Steps

  1. Asset Query - Fetch basic asset metadata from Content Builder
  2. Site Details - Get CloudPages site configuration (siteId, defaultPageId)
  3. State Check - Check published/draft/deleted status
  4. Data Merge - Combine all metadata into enriched asset object
  5. Cache Update - Store enriched data with 15-minute TTL
  6. UI Render - Display enhanced table with all details

API Endpoints

CloudPage Maestro integrates with multiple SFMC API endpoints for comprehensive asset management.

Content Builder API

Endpoint Method Purpose Token
/asset/v1/content/assets/query POST Query assets by type and filters pageHookToken
/asset/v1/content/assets/{id} GET Fetch single asset details pageHookToken

CloudPages API

Endpoint Method Purpose Token
/cloudpages/v1/sites GET List all CloudPages sites appcoreToken
/cloudpages/v1/sites/{id} GET Get site details (siteId, defaultPageId) appcoreToken
/cloudpages/v1/sites/{id}/states GET Get page states (published/draft/deleted) appcoreToken
/cloudpages/v1/sites/{id}/contents GET Fetch HTML content of landing page appcoreToken
/cloudpages/v1/sites/{id}/unpublish POST Unpublish a landing page appcoreToken
API Base

All endpoints are relative to SFMC instance subdomain: https://{subdomain}.rest.marketingcloudapis.com

Authentication

All API requests require proper authentication headers with valid session tokens.

Request Headers

{
  "Authorization": "Bearer {appcoreToken}",  // For CloudPages APIs
  "x-csrf-token": "{pageHookToken}",        // For Content Builder APIs
  "Content-Type": "application/json"
}

Token Validation

Tokens are validated before each API call. If validation fails, user is prompted to refresh the page to re-capture tokens.

Token Expiration

Tokens expire with SFMC session (typically 30-60 minutes). If you encounter 401/403 errors, refresh the page to re-authenticate.

Rate Limits

SFMC APIs have rate limiting to prevent abuse. CloudPage Maestro implements throttling to stay within limits.

Operation Limit Mitigation
Asset Query ~100 req/min Caching, batch requests
Site Details ~50 req/min 15-minute cache TTL
Download ~30 req/min User-initiated, not automated
429 Too Many Requests

If you hit rate limits, wait 1 minute before retrying. Excessive requests may temporarily block your IP.

Cache Strategy

  • TTL: 15 minutes (900,000ms)
  • Key: sfmcAsset_{assetId}
  • Invalidation: Unpublish action clears specific asset cache
  • Storage: localStorage (persistent across page reloads)
Auto-Refresh

Cache automatically refreshes after 15 minutes. Click "Enrich" button to manually force refresh.

Batch Operations

Chrome Extension-exclusive feature for performing actions on multiple assets simultaneously.

Selection System

Each asset row includes a checkbox for multi-selection. Selections persist during enrichment operations to prevent loss of state.

Checkbox Preservation

Checkboxes remain selected even during table re-renders (enrichment every 5 items). State saved in previouslyCheckedIds Set and restored after rendering.

Available Batch Actions

  • Batch Unpublish - Unpublish multiple landing pages at once
  • Batch Publish - Publish multiple draft pages simultaneously
  • Batch Move - Move multiple assets to a different folder

Batch Move Workflow

  1. Select assets using checkboxes (1 or more)
  2. Click "Move Selected" button (appears when items selected)
  3. Folder picker modal opens with searchable tree
  4. Search or navigate folder tree to find target
  5. Click folder name to select destination
  6. Confirm move operation
  7. PATCH API calls sent for each asset
  8. Success/error notifications displayed
  9. Click "Refresh" button to update table

Visual folder tree interface for browsing and selecting folders across your SFMC Content Builder.

Folder Tree Features

  • Search - Real-time filter for folder names
  • Collapsible Tree - Expand/collapse nested folder structure
  • Blue Folder Icons - CSS filter matching SFMC app theme
  • Dynamic Scrolling - Modal height expands with nested folders

Pagination Implementation

SFMC Content Builder API returns max 500 folders per request. Extension loops through pages until all folders fetched:

async function fetchAllFolders() {
  let currentPage = 1;
  let allFolders = [];
  
  while (true) {
    const response = await fetch(
      `https://mc.exacttarget.com/fuelapi/asset/v1/content/categories?` +
      `$page=${currentPage}&$pageSize=500`,
      { headers: { 'x-csrf-token': token } }
    );
    
    const data = await response.json();
    allFolders.push(...data.items);
    
    // Stop when no more items or reached total
    if (data.items.length === 0 || allFolders.length >= data.totalCount) {
      break;
    }
    
    currentPage++;
  }
  
  return allFolders;  // All 1571 folders fetched
}

CORS Bypass

Chrome Extension uses chrome.runtime.sendMessage to send requests through background script, bypassing CORS restrictions:

// content_full.js - Send request to background
const response = await chrome.runtime.sendMessage({
  type: 'MAKE_REQUEST',
  url: apiUrl,
  method: 'PATCH',
  headers: {...},
  body: JSON.stringify(data)
});

// background.js - Execute request with full permissions
chrome.runtime.onMessage.addListener((request, sender, sendResponse) => {
  if (request.type === 'MAKE_REQUEST') {
    fetch(request.url, {
      method: request.method,
      headers: request.headers,
      body: request.body
    })
    .then(res => res.json())
    .then(data => sendResponse({success: true, data}))
    .catch(err => sendResponse({success: false, error: err.message}));
    return true;  // Async response
  }
});

Limitations

Current known limitations and constraints of CloudPage Maestro.

Technical Constraints

  • Token Dependency - Requires active SFMC session; tokens expire with session
  • Rate Limits - SFMC API throttling may delay bulk operations
  • Browser Storage - Cache limited by localStorage quota (~5-10MB)
  • Single BU - Script works within current Business Unit only
  • Network Errors - Offline or network issues prevent API calls

Feature Gaps

  • No bulk download (must download one-by-one)
  • No upload/edit functionality (read-only for downloads)
  • No version history tracking
  • No cross-BU asset management
  • No automated backups
Not Official

This is an unofficial community tool, not supported by Salesforce. Use at your own risk and always maintain backups.

Debug vs Production Logs

Mode Logs Shown Use Case
Production (false) Startup banner, errors, warnings only Normal usage
Debug (true) All API calls, state changes, enrichment steps Troubleshooting, development

Implementation

// Wrapper function controlled by DEBUG_MODE
function debugLog(...args) {
  if (DEBUG_MODE) {
    console.log(...args);
  }
}

// Usage in code
debugLog('Fetching asset:', assetId);          // Hidden in production
console.error('API failed:', error);           // Always shown
debugLog('Enrichment complete:', enrichedData); // Hidden in production
